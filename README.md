## Publish with GitHub Pages (free)
1. Create a **public** GitHub repository named `socials`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. If your GitHub username is `luckytcgguy`, your page will be:
   https://luckytcgguy.github.io/socials/

GitHub Pages is free for public repositories; no trial or subscription is needed.
